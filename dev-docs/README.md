# dev-docs

Tracked, dated, additive logs - the live API audit (account identifiers redacted), the smoke
records, and the release checklist. Nothing here is rewritten; a later finding is a new dated
file or a new section, so the record of what was true on a given day survives.

Session handoffs, build ledgers, and anything carrying real account identifiers live outside
the repo, under the gitignored `docs/`.
