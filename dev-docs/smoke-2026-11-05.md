## Bug found by this smoke

The first `bulk create` dry run failed on both accounts with `links/multiple-by-url: No links
found`, and the installed 0.1.0 failed the same way. See `known-gaps.md`. After the fix, the dry
runs above passed.

at the root, and `.DS_Store` files on disk that are not committed). The install hook, cold against
an empty data dir, printed one install line, and the second run printed nothing, both exit 0.
