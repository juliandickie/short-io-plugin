# Live smoke - 8 November 2026

Version 0.2.0 installed from the outfit catalogue, after the plugin settings fields were emptied
by a reinstall. Read-only, and nothing was created, edited or deleted. Hostnames other than the
public `idd.to` are redacted.

## The settings field

`claude plugin configure short-io@<marketplace>` before and after.

```
before   short_io_api_key - Short.io API Key (optional, sensitive, set)
after    short_io_api_key - Short.io API Key (optional, sensitive, not set)
```

Emptying it in `/plugin manage` left it set. A blank value piped to `--values-stdin` answered
"No configuration changes", and a null value was refused. `claude plugin uninstall
short-io@<marketplace> --keep-data`, then `claude plugin install`, cleared it.

## The bridge in real sessions

`claude mcp list` from a folder no account lists - `plugin:short-io:short-io ... Connected`.

A headless `claude -p` session in each account's folder, allowed only the `get-domains` tool.

```
<an iDD folder>     <domain>, idd.to, <domain>
<a client folder>   <6 domains>
```

Each answered with its own account's domains, so the MCP tools inside a real Claude Code session
pick the account by the session's folder. This closes the item the 2026-11-05 record left open.
